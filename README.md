# ⚜ БогоДел

Браузерная игра в духе «Годвилля», но с настоящим вмешательством: вы — бог, герой живёт сам, а вы отвечаете на молитвы, мечете молнии, строите храм, водите отряды в подземелья и сражаетесь с другими богами.

**Играть:** https://calabok.github.io/bogodel/ (можно установить как приложение — ⚙ Настройки → «Установить», на iPhone: «Поделиться» → «На экран „Домой“»).

## Устройство
- `docs/` — сайт для GitHub Pages: `index.html` (вся игра одним файлом, без зависимостей), `manifest.webmanifest`, `sw.js` (офлайн и автообновление), `version.json`, `icons/`.
- `src/` — исходники игры, собираются в один файл `build.sh`.
- `tests/` — Playwright-тесты (фазз-тест, прицельные, темп прокачки, PWA).
- `tools/` — генерация иконок, шаблон service worker.
- `deploy.sh` — сборка + новая версия service worker + коммит + пуш (у игроков появляется «Доступно обновление»).

Сохранение — в localStorage браузера; перенос между устройствами: ⚙ Настройки → «Экспорт/Импорт сохранения».
